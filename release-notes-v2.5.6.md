# Pastbound v2.5.6 — ModJam Finale

Pastbound 2.5.6 is the final ModJam packaging release for the Echoes of Legend submission.

## What changed

The complete historical gameplay loop remains intact: archive memories, restore relics, travel through the Time Machine, complete dimension-specific expeditions, and preserve the recovered echoes.

The Curator’s Seal reward now behaves like a true final collection item. It is a single, fire-resistant EPIC item rather than a stackable material, making the reward for completing every historical route visually and mechanically distinct. Its English and Turkish display names now identify it directly as the Curator’s Seal.

The release also carries forward the v2.5.5 texture work: the logo is a deterministic 512×512 nearest-neighbor enlargement of the real Time Machine texture, and all ten new historical relic effects have dedicated status-effect icons and localized names.

## Verification

The asset audit passes with 165 models and 106 textures. Java compilation succeeds with Java 25 and NeoForge 26.2.0.66. The release JAR is assembled from the compiled classes and source-controlled resources, with version metadata expanded to 2.5.6.

The project keeps its human-coded style: Turkish identifiers for project-owned variables, methods, and events; no Java comment lines; explicit server validation; and small, readable gameplay systems rather than command-driven shortcuts.

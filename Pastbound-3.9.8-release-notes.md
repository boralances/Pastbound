# Pastbound 3.9.8

## Fixes and improvements

- Added a dedicated End-themed texture for Ervanium Ore.
- Made Olive Saplings respond to bone meal.
- Hardened the custom creative-tab population path.
- Fixed the relic journal so discovered relics retain their completed fragment state and cannot be incorrectly rediscovered.
- Expanded the Field Wiki with controls and troubleshooting guidance.
- Added and normalized crafting recipes for the Ancient, Egyptian, Greek, and Viking boats.
- Added the Boatwright of the Ages and Fleet of Memory advancements.

## Validation

The release was built with `./gradlew check build` using the Java 25 toolchain. JSON resources passed validation, compilation completed successfully, and the release JAR includes the new boat advancements, Ervanium texture, olive sapling behavior, and relic journal fix.

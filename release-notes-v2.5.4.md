## Pastbound v2.5.4

The second new release adds Relic Resonance: the server records distinct relic activations in persistent player data, and activating ten different known relics awards a custom challenge advancement with historical Turkish and English localization.

The release also keeps the faithful 1920×1920 time-machine emblem as the source logo, uses compact 512×512 copies for Minecraft, and includes the version-aware fallback packager so the artifact metadata cannot drift from gradle.properties.

A matching Pastbound-2.5.4.jar is attached. It contains 639 class and resource entries, version 2.5.4 in NeoForge metadata, the high-resolution logo source and in-game logo, the Relic Resonance advancement, and the named relic effect methods.

Validation passed with ASSET_AUDIT_OK for 165 models and 96 textures, clean diff checks, successful Python tool compilation, and successful compileJava validation.
